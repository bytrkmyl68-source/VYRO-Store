# VYRO Store

متجر أزياء عربي HTML/CSS/JS حديث ومهيأ للتطوير.

## المميزات
- واجهة متجر احترافية ومتجاوبة
- فلترة المنتجات حسب التصنيف
- سلة مشتريات داخل الصفحة
- إنشاء حساب إلزامي قبل الشراء
- حفظ الطلبات في localStorage
- لوحة إدارة لإضافة/تعديل/حذف المنتجات
- عرض الطلبات في لوحة الإدارة

## التشغيل
افتح ملف `index.html` مباشرة في المتصفح، أو استخدم أي خادم ثابت مثل:

```bash
python -m http.server 8000
```
ثم افتح الرابط:

```text
http://localhost:8000
```

## لوحة الإدارة
افتح `admin.html` ثم استخدم كلمة المرور التالية:

```text
vyro123456
```

## ملاحظات
هذا الإصدار مناسب للتجربة الأولية ومناسب للتعديلات السريعة. إذا أردت لاحقًا، يمكن ربطه بقاعدة بيانات حقيقية، نظام تسجيل دخول آمن، ودفع إلكتروني.
